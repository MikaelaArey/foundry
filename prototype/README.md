# Foundry prototype

`foundry-prototype.html` is the first clickable prototype of Foundry, the version shared as a claude.ai link. It's a single file: double-click it to open it in your browser. No setup is needed.

It opens with the same example projects and notebook ideas as the claude.ai version. Changes you make are saved in that browser only. The Claude buttons (stress-test, goal suggestions, plan drafts) only work on claude.ai, so they're hidden here.

The full Foundry app, with accounts, the community, the idea generator and the Idea Database, is the rest of this folder. Double-click `Open Foundry.command` one folder up to run it.
